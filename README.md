# ai-agent-platform

## Концепция интерфейса

AI Agent Platform — рабочее пространство с чатом и встроенным редактором. В макете минимум элементов: список чатов слева, разговор в центре, редактор справа по необходимости.

### Чат

В центре отображается переписка. Внизу находится компактное поле ввода сообщения и кнопка «+» для добавления вложений.

### Список чатов

Слева отображается список чатов без лишних панелей. Чаты можно вручную раскладывать по папкам или группировать по тому, где они выполняются: на текущем компьютере, на другом подключённом компьютере, в облаке или на удалённой виртуальной машине.

### Редактор

На широком экране редактор открывается справа рядом с чатом. На телефоне он открывается отдельным экраном внутри приложения, откуда можно вернуться к переписке.

Один текстовый редактор открывает заметки Markdown, обычный текст, исходный код и файлы конфигурации. Файл можно править вручную или попросить ИИ внести изменения прямо из чата. Например: открыть `main.py`, написать в чате, что нужно изменить, и посмотреть обновлённый файл в редакторе.

Это описание макета, а не список уже реализованных функций.
